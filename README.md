# TaskBot — Telegram-бот для задач и созвонов команды

## Что умеет

- Регистрация участников через `/start`. Ты (админ) прописываешься в `ADMIN_IDS`.
- `/newtask` — админ создаёт задачу: название → ответственные (можно несколько) → дата → время.
- `/newrecurring` — повторяющаяся задача (каждый день или раз в неделю), генерируется автоматически.
- Каждому участнику в 10:00 мск приходит его список задач на день + его созвоны + просроченные задачи (отдельным блоком).
- Админу в 10:00 мск приходит сводка по всей команде.
- Кнопка «Сделано ✅» у каждой задачи — участник сам отмечает выполнение.
- Админ может перенести дедлайн (`Перенести дедлайн`) или удалить задачу (`Удалить`) прямо из карточки задачи.
- `/newcall` — назначить созвон: название → участники → дата → время → ссылка. Участникам сразу приходит уведомление «Назначен новый созвон».
- Напоминания о созвоне — за 1 час и за 5 минут, автоматически.
- Отмена созвона кнопкой — напоминания на отменённый созвон не шлются, участники получают уведомление об отмене.
- В 22:00 мск админу приходит вечерний отчёт по дню (сколько сделано / не сделано).
- По пятницам в 18:00 мск — недельная сводка по команде админу.
- `/mystats` — личная статистика участника за 7 дней.
- `/report` — админ получает CSV-выгрузку по всей команде.
- `/team` — список команды (админ).
- Новые задачи, добавленные в течение дня, в моменте не присылаются — только в следующем утреннем списке (как договаривались).
- Минимум оформления: везде используются только два значка — ▪️ и ✅ — плюс баннер-картинка к каждому типу сообщения.

## Как всё это запустить с нуля

### 1. Создать бота в Telegram
1. Напиши в Telegram боту **@BotFather** → `/newbot` → придумай имя и username.
2. Он даст токен вида `123456789:AAExxxxxxx` — сохрани его, это `BOT_TOKEN`.
3. Узнай свой telegram_id: напиши боту **@userinfobot**, он покажет твой ID — это будет `ADMIN_IDS`.

### 2. Залить код в GitHub
1. Создай пустой репозиторий на github.com (например `taskbot`).
2. В папке проекта:
   ```
   git add .
   git commit -m "Initial taskbot"
   git branch -M main
   git remote add origin https://github.com/<твой-аккаунт>/taskbot.git
   git push -u origin main
   ```

### 3. Развернуть на Railway
1. Зайди на railway.app → New Project → **Deploy from GitHub repo** → выбери `taskbot`.
2. В этом же проекте нажми **New → Database → PostgreSQL** — Railway сам поднимет базу.
3. Открой сервис бота → вкладка **Variables** → добавь:
   - `BOT_TOKEN` = токен от BotFather
   - `ADMIN_IDS` = твой telegram_id (через запятую, если админов несколько)
   - `DATABASE_URL` = зайди в сервис Postgres → Variables → скопируй `DATABASE_URL`, но замени в начале
     `postgresql://` на `postgresql+asyncpg://` (это нужно для асинхронного драйвера).
4. Railway сам возьмёт `Procfile` (`worker: python main.py`) и `requirements.txt`, установит зависимости и запустит бота.
5. Проверь логи во вкладке **Deployments** — там должно быть видно, что бот стартовал без ошибок.

### 4. Первый запуск
1. Напиши боту `/start` — ты зарегистрируешься как админ.
2. Попроси остальных участников команды тоже написать `/start` в бота.
3. Дальше пользуйтесь командами: `/newtask`, `/newrecurring`, `/newcall`, `/report`, `/team`, `/mytasks`, `/mystats`.

## Важно: обновления бота не требуют перерегистрации команды

Все пользователи хранятся в Postgres, а не в памяти бота. Когда ты правишь код и делаешь `git push`,
Railway просто пересобирает и перезапускает процесс — токен бота и база остаются те же самые,
поэтому никто из команды не теряет регистрацию и никого не нужно просить снова нажимать `/start`.
Не создавай нового бота через BotFather и не меняй `BOT_TOKEN` — тогда всё останется как есть.

## Настройки, которые легко поменять

Всё в файле `bot/config.py`:
- `MORNING_DIGEST_TIME` / `EVENING_REPORT_TIME` — время утреннего списка и вечернего отчёта.
- `WEEKLY_SUMMARY_DAY` / `WEEKLY_SUMMARY_TIME` — когда приходит недельная сводка.
- `EMOJI_MARK` / `EMOJI_DONE` — те самые два смайлика оформления.
